UO Ultimate Dexxer Attack Script by Mike|Walker

It's an All-In-One attack script for Ultima Online Dexxer templates (Melee, Sampire, Ninja, Archer, Thrower etc.). The script was mostly tested on UOAlive.

The gump script is used to set the attack options. Once you have set and saved all option you only need the gump script when you want to change the settings.
