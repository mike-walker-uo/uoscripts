UO Ultimate Dexxer Attack Script by Mike|Walker

It's an All-In-One attack script for Ultima Online Dexxer templates (Melee, Sampire, Ninja, Archer, Thrower etc.). The script was mostly tested on UOAlive.

The gump script is used to set the attack options. Once you have set and saved all option you only need the gump script when you want to change the settings.

![Gump Script options](attackscriptgump.png "Gump Script Options")

## Features

- Supports melee, archery, throwing, ninja, pet and summon builds. Attack, Honor and range behavior can be adjusted through the GUMP.
- Selects weapon abilities for single targets and groups, re-arms specials for successive swings, and uses Lightning Strike or Momentum Strike as mana-aware fallbacks. Weapon specials can be disabled separately.
- Optional Chivalry, Bushido, Ninjitsu, Necromancy, Spellweaving and mastery actions, including healing, defensive abilities and combat buffs.
- Ninjitsu support includes Mirror Image management, White Tiger Form, Death Strike, Focus Attack and a Shadow Strike/Stealth/Backstab cycle with optional smoke or egg bombs.
- Blood Oath handling uses an Enchanted Apple only for Blood Oath, then falls back to Remove Curse. While affected, combat is restricted to Whirlwind against groups of more than two enemies.
- Per-character slayer weapon and talisman sets with automatic swapping, manual selection and hold mode.
- Pet and summon target synchronization, automatic potions, trapped-crate use, Bag of Sending support, supply warnings and optional dress-list maintenance.
- Moves selected artifacts into a saved loot bag and drops Chest of Heirlooms items from the backpack.
- Configurable target filters, permanent per-character mob ignores, distance markers, rare-mob warnings and combat-blocking legendary or astral pet alerts.
- Settings and slayer sets are saved separately for each character. The GUMP only shows combat options for which the character meets the skill requirements.
